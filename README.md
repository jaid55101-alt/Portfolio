# Jai Dev | Portfolio

A responsive personal portfolio showcasing my web development journey, skills, and projects. Built with vanilla HTML, CSS, and JavaScript.

## Overview

The site introduces me as a learning web developer based in India and includes:

- About, skills, and learning journey sections
- Selected web and Android project concepts
- Responsive navigation for mobile screens
- Scroll-based reveal effects and project-link notifications
- Contact and social links

## Projects

| Project | Description | Technologies |
| --- | --- | --- |
| Shopping Portal | Product storefront concept using the Fake Store API | HTML, CSS, JavaScript, Fetch API |
| News Website | News cards rendered from API data | HTML, CSS, JavaScript, API |
| Weather Website | Weather app concept in progress | HTML, CSS, JavaScript, Weather API |
| SocialX | Social app concept for Android | Kotlin, Jetpack Compose |
| JARVIS AI | Voice assistant concept | Python, speech recognition, text-to-speech, AI APIs |

Project links are placeholders in the portfolio and can be added as projects are published.

## Run Locally

No build tools or dependencies are required.

1. Clone this repository:

   ```bash
   git clone https://github.com/yourusername/portfolio.git
   ```

2. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Built With

- HTML5

- Google Fonts: Manrope and DM Mono

## Customize

Before publishing, update the placeholder GitHub and LinkedIn URLs and email address in `index.html`. Replace the project links when the projects are available, and update this README's clone URL to match your GitHub username and repository.
